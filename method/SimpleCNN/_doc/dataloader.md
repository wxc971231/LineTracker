# SimpleCNN 训练数据在线构造

## 1. 目标与原则

Dataloader 直接从完整合成序列中在线裁剪训练块，不预先把大量重叠的 $20\times10000$ 块保存到磁盘。每个完整序列含 $F=300$ 帧、每帧 $R=300000$ 个距离 bin。训练块始终保持与推理一致的形状：

$$
F_{\mathrm{line}}\times W_R=20\times10000.
$$

在线构造只能减少存储和精确重复的裁剪样本，不能凭空产生新的背景噪声。因此应随机化时间窗与空间起点，并在同一时刻缓存多份完整序列，避免连续 batch 主要来自同一个背景序列。

本文符号与 [SimpleCNN 方法说明](SimpleCNN.md) 一致：$I_\tau$ 表示第 $\tau$ 帧是否存在已标注目标响应，$d_\tau$ 表示实际响应的块内零基距离 bin，$H=\sum_\tau I_\tau$。置信度标签 $q^*$ 为二值目标，`q_valid` 表示它是否参与监督，`is_positive` 表示潜在轨迹完整位于块内且 $H>0$ 的可见正样本。

## 2. 原始样本字段与用途

每个 `data.npz` 至少读取以下字段：

| 字段 | 形状 / 类型 | 用途 |
|---|---|---|
| `observation_packed` | `[300, 37500]`，`uint8` | 打包后的原始二值观测；训练输入唯一使用的观测字段。 |
| `target_hit` | `[300]`，`bool` | 生成 $I_\tau$。 |
| `target_hit_bin` | `[300]`，`int32` | 生成有响应帧的实际距离标签 $d_\tau$。 |
| `target_true_range_m` | `[300]`，`float32` | 仅用于判断潜在轨迹与裁剪块是完整包含、部分相交还是完全不相交；不作为网络输入或损失标签。 |

`target_true_range_m` 的作用只是采样资格判定，不会泄漏给网络。几何损失始终只使用 `target_hit` 和 `target_hit_bin` 导出的 $I_\tau,d_\tau$。

## 3. 在线 batch 构造

当前实现为 `BalancedTrainBatchIterableDataset`：数据集的每次迭代直接产生一个完整 batch，而不是先产生单样本再依赖普通 `shuffle` 拼 batch。这样可严格保持正负比例。

设正样本比例为可调参数 $\alpha_{\mathrm{pos}}\in(0,1)$，默认取 $\alpha_{\mathrm{pos}}=0.25$。对任意 $B\ge2$，每个 batch 的正负样本数定义为：

$$
N_{\mathrm{pos}}
=
\min\left(
B-1,
\max\left(1,\left\lfloor B\alpha_{\mathrm{pos}}+\frac{1}{2}\right\rfloor\right)
\right),
\qquad
N_{\mathrm{neg}}=B-N_{\mathrm{pos}}.
$$

这允许任意 batch size；实际比例与 $\alpha_{\mathrm{pos}}$ 的偏差至多来自一个样本的舍入。默认设置下，$B=32$ 产生 8 个可见正样本和 24 个负样本，$B=30$ 则产生 8 个可见正样本和 22 个负样本。构造完成后在 batch 内随机打乱顺序。每个 worker 维护 $K=4\sim8$ 个已加载的完整样本`.npz`；一份序列累计提供到设定额度，例如 32～128 个正样本后即从缓存池替换。额度是控制样本相关性的工程参数，并不表示该序列的所有可能裁剪已经“耗尽”。

多 worker 时，各 worker 获得互不重叠的原始序列路径，并使用由 `(global_seed, rank, worker_id, stream_generation)` 派生的随机数生成器，避免不同 rank 或 worker 产生相同随机序列；断点恢复时递增 `stream_generation`，使训练重新随机取样而不是从旧数据流开头重放。

训练集应实现为无限迭代流，训练预算由优化器更新步数而不是 epoch 数决定。每个 worker 维护一份随机排列的训练序列路径列表；缓存池需要替换来源时，按该列表顺序取下一份序列。列表全部取完后重新随机排列；该排列只决定来源替换顺序，不单独记录 epoch 或作为训练停止条件。

## 4. 正样本构造

### 4.1 随机时间窗

对选中的完整序列，随机选择时间窗起点：

$$
t_n\in\{0,1,\ldots,F-F_{\mathrm{line}}\}.
$$

当前块对应的原始帧为 $t_n,t_n+1,\ldots,t_n+19$。这比只使用不重叠的 20 帧窗口提供更多时间位置，同时仍满足局部近似直线假设。

### 4.2 保持标准形状的随机空间裁剪

正样本的形状始终是 $20\times10000$，但训练时不宜只使用推理阶段固定的 9 km 步进块。应随机选择空间起点 $s$，使完整潜在轨迹位于块内，且与边界保留裕量 $g$。

记当前 20 帧潜在轨迹的最小、最大距离为 $r_{\min},r_{\max}$，则有效起点区间为：

$$
\max\left(0,r_{\max}+g-W_R\right)
\le s\le
\min\left(R-W_R,r_{\min}-g\right).
$$

推荐 $g=50\sim200\ \mathrm m$。随机裁剪能使目标在块内位置更均匀，避免网络学习固定分块网格的位置先验；同时建议保留约 30% 的正样本使用推理阶段的标准块起点 $0,9000,\ldots,288000,290000$，以保持训练与推理的分块分布一致。

### 4.3 标签生成

对于块 $(t_n,s)$，逐帧生成：

$$
I_\tau
=
\mathbf 1\!\left(
\texttt{target\_hit}[t_n+\tau]\ \land\
s\le
\texttt{target\_hit\_bin}[t_n+\tau]
<s+W_R
\right),
$$

$$
d_\tau
=
\texttt{target\_hit\_bin}[t_n+\tau]-s,
\qquad I_\tau=1.
$$

无响应帧的 $d_\tau$ 在数据张量中填充为 `-1`，但因 $I_\tau=0$ 会被损失掩码排除。窗口内实际响应数为：

$$
H=\sum_{\tau=0}^{19}I_\tau.
$$

结合潜在轨迹与当前块的空间关系，标签按下表生成：

| 样本类型 | 条件 | $q^*$ | `q_valid` | `is_positive` |
|---|---|---:|---:|---:|
| 可见正样本 | 潜在轨迹完整位于块内，且 $H>0$ | 1 | `True` | `True` |
| 零证据样本 | 潜在轨迹完整位于块内，但 $H=0$ | 0（仅张量占位） | `False` | `False` |
| 部分相交负样本 | 潜在轨迹与块相交，但未完整位于块内 | 0 | `True` | `False` |
| 背景负样本 | 潜在轨迹与块完全不相交 | 0 | `True` | `False` |

`q_valid=False` 表示对应的 q 占位值不参与 BCE；`is_positive=True` 同时表示该块参与几何损失，代码中不再单独保存 `m_line`。

在线训练只构造可见正样本和 `q_valid=True` 的四类负样本，因此零证据样本不进入训练；固定验证/测试网格仍保留零证据样本，并在评估时通过 `q_valid` 忽略其 q 损失。

## 5. 负样本构造

训练负样本分为三类完全不相交背景块和一类部分相交困难负样本。不能只用“块内没有实际响应”判负，因为这也可能是完整目标块中的零证据情况；空间关系只用 `target_true_range_m` 判定，不会交给网络。

每次构造一个负样本时，先按四项相对权重 $w_k$ 随机选择类别，其实际概率为：

$$
p_k=\frac{w_k}{\sum_j w_j}.
$$

当前四项默认权重均为 `1.0`，归一化后每类负样本的期望概率均为 $1/4$；类别是逐样本随机选择的，因此单个 batch 不保证严格四等分。默认 `positive_fraction=0.25` 时，正样本占 25%、全部负样本占 75%，每类负样本长期约占整个 batch 的 18.75%；例如 $B=32$ 时固定产生 8 个正样本和 24 个负样本，四类负样本期望各 6 个。

1. **同时间窗局部负样本：** 使用正样本的 $t_n$，从目标轨迹附近但不相交的空间区域裁剪，是主要困难背景负样本。
2. **同时间窗分层负样本：** 使用正样本的 $t_n$，在不相交的有效距离区域中按近场、过渡区、远场分层采样。
3. **随机时空负样本：** 从缓存池任意序列、随机时间窗和不相交距离区域抽取，补充不同背景强度和噪声状态。
4. **部分相交负样本：** 使用正样本的 $t_n$，令潜在轨迹进入当前块但被左边界或右边界截断，以训练 q 头排斥不完整目标块。

前三类背景负样本的“不相交”可通过当前时间窗的 $r_{\min},r_{\max}$ 与块 $[s,s+W_R)$ 判断。若使用保护带 $g_{\mathrm{neg}}$，可要求：

$$
s+W_R\le r_{\min}-g_{\mathrm{neg}}
\quad\text{或}\quad
s\ge r_{\max}+g_{\mathrm{neg}}.
$$

四类负样本均设置 $q^*=0$、`q_valid=True`、`is_positive=False`。

不要在“目标实际可见”的同一输入块上随机指定一条错误斜率或错误距离并标成负样本。当前网络直接从一个块回归唯一候选线，这会形成矛盾监督。随机候选线负样本只适用于把候选线 $(\rho,\nu)$ 也作为输入的候选线评分器，不适用于当前 SimpleCNN。

## 6. 从压缩二值数据提取块

不应对每个样本解包完整的 $300\times300000$ 矩阵。对于空间起点 $s$，令：

$$
j_0=\left\lfloor\frac{s}{8}\right\rfloor,
\qquad
o=s\bmod 8,
\qquad
J=\left\lceil\frac{o+W_R}{8}\right\rceil.
$$

只读取：

```python
packed[t_n:t_n + 20, j_0:j_0 + J]
```

将该片段按合成器使用的相同 `bitorder` 解包为 `[20, 8J]`，再截取：

```python
window = unpacked[:, o:o + W_R]  # [20, 10000]
```

这也允许 $s$ 不是 8 的倍数，从而实现块内随机平移和随机模 8 相位增强。输出可先保持 `uint8` 或 `bool`，在送入网络前转换为 `float32`。随后按局部距离索引的 `mod 8` 规则重排为：

$$
[20,10000]\longrightarrow[8,20,1250].
$$

SimpleCNN-v1 不对原始 $0/1$ 数据做背景归一化或显著性变换。

## 7. 单个 batch 的返回格式

在线训练与固定网格数据集统一返回：

```python
{
    "x": ...,              # float32, [B, 8, 20, 1250]
    "I": ...,              # bool,    [B, 20]
    "d": ...,              # int64,   [B, 20]；无响应帧为 -1
    "q": ...,              # float32, [B]；二值置信度标签 0/1
    "q_valid": ...,        # bool,    [B]；是否计算该样本的 q 损失
    "is_positive": ...,    # bool,    [B]；完整可见正样本，也是几何损失块级掩码
}
```

置信度 BCE 只统计 `q_valid=True` 的样本。逐帧 Huber 同时使用 `is_positive` 选择可见正样本块、使用 $I$ 选择其中具有实际响应的帧，`d=-1` 的填充值绝不参与损失。

在线训练 batch 构造完成后会随机打乱正负样本顺序，防止 BatchNorm 或调试代码依赖样本排列。

## 8. 划分与运行时检查

训练、验证、测试应按完整 `data.npz` 序列划分，再由各自集合在线裁剪；严禁把同一完整序列的不同时间窗或不同空间块分到不同集合。

训练集保持随机在线构造；验证集和测试集则采用与真实推理一致的**标准分块网格**，不使用随机空间裁剪，也不按 $1:3$ 平衡正负样本。

验证时间窗长度固定为 $F_{\mathrm{line}}=20$ 帧。时间方向使用可调验证步进 $S_T^{\mathrm{val}}$，其单位为帧，且必须满足：

$$
S_T^{\mathrm{val}}\in\mathbb Z_{\ge1}.
$$

对一份 $F$ 帧验证序列，验证时间窗起点集合为：

$$
\mathcal T_{\mathrm{val}}
=
\left\{
0,S_T^{\mathrm{val}},2S_T^{\mathrm{val}},\ldots,
\left\lfloor\frac{F-F_{\mathrm{line}}}{S_T^{\mathrm{val}}}\right\rfloor
S_T^{\mathrm{val}}
\right\}
\cup
\left\{F-F_{\mathrm{line}}\right\}.
$$

其中末尾窗口强制补入，以覆盖最后一帧。$S_T^{\mathrm{val}}=1$ 时，对每个连续 20 帧窗口都验证一次；更大的步进可降低验证开销，但不会改变单个窗口的输入形状。

距离方向严格使用推理阶段的标准块起点：

$$
\mathcal S_R
=
\{0,9000,18000,\ldots,288000,290000\}.
$$

因此每个验证序列的完整评估块集合为：

$$
\mathcal V
=
\left\{
(t_n,s):
t_n\in\mathcal T_{\mathrm{val}},\ s\in\mathcal S_R
\right\}.
$$

首次划分验证/测试集后，应保存 schema v3 标准网格清单。清单记录 source、时间窗起点、空间起点、紧凑的 `response_mask`（$I$）、`response_bin`（$d$）、`is_positive` 和 `q_valid`；二值 q 可由 `is_positive` 无损生成，不保存 `m_line`。清单保留全部标准网格块，包括可见正样本、零证据块、部分相交块和完全背景块；测试集同样使用独立且固定的标准网格清单。

schema v3 标准网格缓存放在全局 `runs/_cache/val_test_grid/` 下。缓存键包含 schema 版本、数据划分、源文件相对路径与大小/mtime、时间步进和所有会影响网格或标签的参数，因此旧版本不会被误用。命中缓存时检查 schema、数组头和 source 签名，训练/独立评估的 rank 0 还会随机复算 10 个标签样本；源文件发生变化或校验失败时重建。训练启动仅预处理 validation，test 在独立评估首次使用时生成。

完整评估以 source 为单位将互不重叠的数据分给各 rank；设置 `max_eval_batch_num > 0` 时，每次评估调用都会在各 rank 内有放回地重新抽取 source 及其块，但每个 batch 仅来自一个 source，以减少完整 `data.npz` 的重复解压。

排查采样问题时，可按需增加以下诊断；当前默认训练日志不持续记录这些明细：

- 实际正负样本比例，以及四类负样本各自的采样比例；
- $H=0,1,\ldots,20$ 的直方图、样本距离区域、每帧背景响应数和来源序列分布；
- local、same-time、random 三类负样本是否与潜在轨迹完全不相交；
- partial 负样本是否与潜在轨迹相交但未完整包含，并满足 `q=0, q_valid=True, is_positive=False`；
- 有效位置的 $d_\tau$ 是否始终满足 $0\le d_\tau<W_R$；
- 解包、裁剪、重排和 batch 生成的耗时。

这些可选检查可用于定位标签错位、压缩位序错误、近场/远场采样失衡，以及同一原始序列被过度重复使用的问题。
